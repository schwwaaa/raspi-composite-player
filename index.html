01 / System

A simple tool for a stubbornly specific job.

Raspi Composite Player turns a Raspberry Pi 3B+ into a single-purpose media deck for composite televisions. Place prepared MP4 files in the media folder, apply power, and the playlist begins automatically.

Files play in alphanumeric order and repeat continuously. Optional keyboard or numeric-keypad controls provide pause, seek, previous, and next without exposing a desktop interface.

02 / Applications

Built for places where a laptop is too much and a DVD player is not enough.

Use the imperfect, low-resolution signal as part of the work—not merely as a way to reach the screen.

A–01

Autonomous video artwork

Hide the Pi inside or behind a CRT. When gallery power comes on, the artwork starts. When power goes off, it stops.

A–02

Faux television channel

Sequence station IDs, films, interstitials, fake advertisements, test cards, and continuity announcements.

A–03

Archive station

Present oral histories, home movies, public-access footage, or local collections on an era-appropriate display.

A–04

Live source deck

Feed composite output into a VCR, analog mixer, dirty mixer, capture device, or feedback chain.

A–05

Video edition

Distribute a complete audiovisual publication as an SD card, Pi, cable, and labeled controller.

03 / Setup

Five steps from blank card to composite playback.

The image is intended to behave like an appliance. Preparation happens once; daily operation is simply power on and power off.

  1. 01

    Download the image

    Get the current release and verify any release-specific notes in the repository.

  2. 02

    Flash an SD card

    Use Raspberry Pi Imager, balenaEtcher, or another raw-disk imaging tool.

  3. 03

    Prepare media

    Encode videos for 720 × 480 playback, then copy them into /home/mediaplayer/media.

  4. 04

    Connect composite A/V

    Use a compatible TRRS-to-RCA cable from the Raspberry Pi 3B+ to the television.

  5. 05

    Apply power

    The player boots, loads the media directory, and begins the repeating playlist.

04 / Specifications

Prepare for the display you are actually using.

Pre-scaling footage reduces work during playback and gives more predictable framing on a 480-line composite display.

Target device
Raspberry Pi 3 Model B+
Output
Composite video + stereo audio
Frame

Video

Audio

Playlist

FFMPEG / REFERENCE ENCODE
ffmpeg -i input.mp4 \
  -vf "scale=720:480:force_original_aspect_ratio=decrease,\
pad=720:480:(ow-iw)/2:(oh-ih)/2" \
  -r 30000/1001 \
  -pix_fmt yuv420p \
  -c:v libx264 -profile:v baseline -level 3.0 \
  -b:v 1500k \
  -c:a aac -ar 44100 -ac 2 -b:a 128k \
  output_pi_crt.mp4
